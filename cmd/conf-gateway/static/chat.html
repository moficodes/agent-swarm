Welcome to Agent Substrate.

This agent is yours. Gemini writes a Python script for each request, and it runs in a gVisor sandbox only after you approve it.

Between turns your agent is suspended: its memory is saved as a snapshot, its /workspace volume stays bound to your actor, and it gives up its place on the worker until your next message. Try Keep a diary twice or Filestore disk vs. RAM to watch its files follow it across workers.

Pick an example above, or ask for anything a short Python script can do.
